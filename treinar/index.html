# onde treinar

Começou agora? Siga a trilha abaixo, no seu ritmo. Uns 3 a 5 horas por semana bastam. Já tem base? Pule direto para as plataformas, os jogos de devops e cloud ou as ferramentas de appsec.

> trilha

  1. fase 0 · semanas 1–2

    Terminal e Linux

    Todo CTF passa pelo terminal. Faça o Bandit ↗ até o nível 10, pelo menos. Travou no começo? Tem o nosso writeup dos níveis 0 a 3.

    Meta: se virar com ssh, ls -la, cat, find, grep e pipes (|).

  2. fase 1 · semanas 3–4

    Primeiros desafios de verdade

    No picoGym ↗, resolva os desafios fáceis de General Skills e depois experimente um ou dois de cada categoria: web, crypto, forensics, reversing.

    Meta: 15 desafios resolvidos e uma noção de qual categoria você mais curtiu.

  3. fase 2 · semanas 5–8

    Escolha uma categoria e aprofunde

    Web: labs Apprentice da PortSwigger ↗. Crypto: trilha Introduction do CryptoHack ↗. Pwn e reversing: primeiros módulos do pwn.college ↗. Forense: labs fáceis do CyberDefenders ↗.

    Meta: aprender Python básico para scripts (requests, pwntools ou o que a categoria pedir).

  4. fase 3 · a partir da semana 8

    Primeiro CTF com o time

    Escolha na agenda um CTF jeopardy, aberto e de peso baixo, e jogue com a gente. Não precisa resolver muito: o objetivo é viver um evento. Depois, escreva um writeup de pelo menos um desafio, mesmo que você só tenha chegado perto.

    Meta: uma flag em competição e o primeiro writeup publicado.

Travou? Normal. Faça assim:

  • Timebox de 45 minutos. Sem progresso, mude de abordagem ou de desafio. Insistir no escuro é o que mais faz gente desistir.
  • Anote tudo. O que tentou, o que viu, o que não entendeu. Metade das vezes a resposta aparece na hora de escrever.
  • Peça dica, não a resposta. Explique o que já tentou. O time ajuda.
  • Leia o writeup depois que o evento acabar e refaça sozinho. É assim que se aprende de verdade.
  • IA ajuda a estudar (explicar um conceito, um trecho de código), mas siga sempre a regra do evento e entenda o que está fazendo.

> devops e cloud jogando

Muito desafio de CTF roda em container, pipeline ou nuvem. Entender a infra ajuda a atacar e a defender. Menos tutorial, mais quebrar (e consertar) coisas.

Terminal e Git

  • cmdchallenge ↗Desafios de Bash em uma linha. Bom depois do Bandit. grátis
  • Vim Adventures ↗Aprenda Vim jogando um RPG. freemium
  • Learn Git Branching ↗Branch, rebase e merge visual, no navegador. grátis
  • Oh My Git! ↗Jogo de cartas open source para entender Git. grátis

Containers e Kubernetes

  • K8s Games ↗Conceitos de Kubernetes em formato de jogo. grátis
  • learn-docker-and-k8s ↗Repositório com exercícios práticos de Docker e K8s. grátis

SRE e troubleshooting

  • SadServers ↗Servidores Linux quebrados de verdade para você consertar. freemium
  • devops.games ↗Jogos de estratégia e cultura DevOps. grátis

Cloud

  • AWS Cloud Quest ↗RPG da AWS com labs reais na nuvem. freemium
  • Google Skills ↗Labs e trilhas de Google Cloud. freemium

> ferramentas de appsec

Open source para proteger o seu próprio código, depois do CTF. Use só em sistemas que são seus ou que você tem autorização para testar.

Scanners e SAST

  • Semgrep ↗Análise estática com regras que parecem o próprio código. open source
  • Trivy ↗CVEs, misconfig, segredos e SBOM em imagens, IaC e K8s. open source
  • Nuclei ↗Scanner de vulnerabilidades com templates YAML da comunidade. open source

Segredos e malware

  • TruffleHog ↗Acha e valida credenciais vazadas em repositórios. open source
  • ClamAV ↗Antivírus clássico, bom para escanear uploads. open source

Revisão de código com IA

  • Claude Code Security Review ↗GitHub Action que revisa a segurança de cada PR. open source
  • Codex Security ↗CLI da OpenAI para achar e corrigir vulnerabilidades. open source
  • Cloudflare Security Audit ↗Skill de auditoria em fases para agentes de código. open source
  • Strix ↗Agentes de IA que fazem pentest no seu app. open source

Segurança de IA

  • PyRIT ↗Framework da Microsoft para red team de IA generativa. open source
  • SkillSpector ↗Verifica skills e MCPs de agentes antes de instalar. open source
